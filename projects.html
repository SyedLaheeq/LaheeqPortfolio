FOREO Skin-GPT — AI Skincare Diagnostic Consultant

Built at FOREO Labs as an in-app AI beauty consultant that turns mobile skincare diagnostics into a personalized wellness loop. Uses OpenCV for real-time image preprocessing (normalization and illumination correction) coupled with SAM 3 for zero-shot semantic facial zone mapping. A RAG pipeline queries a local vector database of dermatological guidelines and FOREO product specifications, combining retrieved domain knowledge with visual metrics via local Edge AI (Qwen) and an LLM agent workflow (Claude/Hermes) for structured JSON function-calling directly into user-specific FOREO device parameters.

OpenCV SAM 3 RAG Qwen (Edge AI) Claude / Hermes JSON Function Calling

Distributed LLM Fine-Tuning (Master's Thesis)

Uppsala University Master's thesis integrating Rotated LoRA (RoLoRA) into a sparse federated learning framework to fine-tune Llama-3-8B across decentralized participants without sharing raw data. Evaluated resilience against Byzantine attacks (Lie, Scaling, and Inverse Gradient) via GPU experiments on SLURM using PyTorch, Hugging Face PEFT, and Weights & Biases.
